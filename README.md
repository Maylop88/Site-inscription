# Tu tires ou tu pointes — Site d'inscription

## Structure du dossier VS Code
- `index.html` : Page principale du site d'inscription (prête pour GitHub Pages)
- `js/inscription.js` : Logique JavaScript du formulaire reliée à Google Sheets
- `google-apps-script.gs` : Code serveur à coller dans Google Sheets > Extensions > Apps Script

## Mise en place rapide dans VS Code
1. Décompressez ce dossier et ouvrez-le dans **VS Code** (`Fichier > Ouvrir le dossier`).
2. Ouvrez `js/inscription.js` et remplacez `COLLEZ_ICI_VOTRE_URL_APPS_SCRIPT_EN_EXEC` par votre lien complet `https://script.google.com/macros/s/.../exec`.
3. Déposez `index.html` et le dossier `js/` sur votre dépôt **GitHub** (en conservant bien le dossier `js/` avec `inscription.js` dedans).
